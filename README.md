# Sweet Destruction 

Website desenvolvido para apresentar o projeto Sweet Destruction, participante da competição RoboCup durante o NEXT FIAP 2026.

## Sobre o projeto

O Sweet Destruction foi desenvolvido para a experiência da competição, envolvendo tecnologia, robótica, criatividade e trabalho em equipe. O site apresenta a proposta do projeto e os principais aspectos envolvidos no desenvolvimento.

## Tecnologias

- HTML5
- CSS3

## Evento

NEXT FIAP 2026  
Competição RoboCup

## Equipe

Projeto desenvolvido em equipe durante a experiência acadêmica no NEXT FIAP 2026.
